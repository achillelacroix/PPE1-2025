Miniprojet

Le miniprojet vise à nous préparer pour le projet. Nous l'avons élaboré au cours des séances en le rendant progressivement plus complexe. Pour accéder au tableau final issu du miniprojet, cliquez ici.

Les étapes du miniprojet

Le miniprojet s'est construit après plusieurs étapes :

  1. Au départ, le programme devait simplement afficher les adresses d'un fichier, la réponse http, l'encodage de la page et le nombre de mots contenus sur la page ;
  2. Ensuite, il a fallu modifier le programme pour afficher le résultat dans un tableau ;
  3. Puis, transformer la sortie pour qu'elle donne un fichier html contenant le tableau ;
  4. Enfin, ajuster une dernière fois le programme pour qu'il suive le stylesheet Bulma.
